# Angry Birds · FPGA 版（高云 GW1N-9 / VGA / UART）

> 2025 全国大学生 FPGA 创新设计大赛参赛作品 —— 用纯 RTL（无 CPU、无软核）在
> 高云 GW1N-9 上实现的一款 640×480 VGA 实时像素游戏，通过串口（电脑 / 蓝牙模块）操作。

**三个关键词：`FPGA` · `VGA 实时图形` · `UART 交互`**

---

## 1. 作品简介

整个游戏没有使用 MCU 或软核处理器，全部逻辑由 SystemVerilog / Verilog 描述：
时钟管理、视频时序生成、像素级图形合成、碰撞与状态机、串口接收、数码管显示
分别由独立模块完成，数据流是一条从 `uart_rx` / `game_ctrl` 到 `display` 再到
`rgb_timing` 的纯硬件流水线。

- 分辨率：640×480 @ 59.5 Hz（像素时钟 25 MHz）
- 色彩：RGB444，12 bit
- 小鸟、管道、背景、开始/结束画面全部存放在片上 BSRAM 中（`$readmemh` 预加载）
- 操作：任意非 0 串口字节 = 扇翅膀，`0x00` = 软复位
- 板载 6 位数码管同步显示最近一次收到的串口字节（十六进制）

> ⚠️ 命名说明：工程目录名为「愤怒的小鸟」，但实际玩法是 **Flappy Bird**
> （点击上升、穿过管道间隙、撞管/出界结束）。若要参赛展示，建议统一命名口径。

## 3. 目录结构

```
niao/
├── niao.gprj          # 高云云源软件工程文件（仓库中已补齐）
├── niao.sdc           # 时序约束（50 MHz 输入时钟）
├── top.sv             # 顶层：例化 PLL / 时序 / 显示 / 游戏控制 / 串口 / 数码管
├── top.cst            # 物理约束（引脚分配）
├── video_pll.v        # rPLL IP：50 MHz → 25 MHz；并产生 100 kHz 数码管扫描时钟
├── rgb_timing.sv      # VGA 640×480 时序发生（hs/vs/de/x/y）
├── display.sv         # 像素合成：背景 + 5 根管道 + 小鸟 + START/END 画面，2 级流水线
├── game_ctrl.sv       # 游戏状态机、重力/跳跃、管道滚动与伪随机高度、碰撞判定
├── uart_rx.v          # 串口接收（5 状态 Moore/Mealy 混合机，9600 @ 25 MHz）
├── seg.v              # 6 位数码管动态扫描（只用了 2 位）
├── background.c       # 80×60 背景调色板（$readmemh，12 bit/像素）
├── bird.c             # 32×32 小鸟位图（1024 项）
├── tube.c             # 56×32 管道贴图（1792 项）
└── state.c            # 256×128 的 START / END 两幅画面（4096 项）
```

## 4. 编译与运行

1. 安装 **Gowin 云源软件（Gowin EDA）**，版本 ≥ V1.9.8（PLL IP 由该版本生成）。
2. ⚠️ **先把本仓库放到纯英文路径下**（例如 `D:\fpga\angry_birds`）。
   厂商文档明确提示「程序路径不能存在中文字符」，`$readmemh` 在中文路径下可能读不到 ROM 文件。
3. 用云源软件打开 `niao.gprj`，器件选择 `GW1N-LV9LQ144C6/I5`。
4. 依次执行 综合（Synthesize）→ 布局布线（Place & Route）→ 生成比特流。
5. 用 Gowin Programmer + 下载器烧录 `.fs` 到 FPGA（SRAM 模式）或外部 Flash。
6. 串口工具（如 XCOM）设置 **9600 / 8 / N / 1**：
   - 发送任意非 `0x00` 字节 → 小鸟上升
   - 发送 `0x00` → 软复位回到开始画面
   - 蓝牙调试助手同理（蓝牙模块与 WiFi 模块波特率均为 9600）

> 若综合时报 `$readmemh` 找不到文件：把 4 个 `.c` 文件复制到云源软件的工作目录
> （通常是工程同级或 `impl/temp`），或改用绝对路径。

## 5. 设计要点

- **纯硬件像素流水线**：`display.sv` 把 ROM 寻址、取数、合成拆成 2 级寄存器流水线
  （`_r0` / `_r1` 信号），保证 25 MHz 像素时钟下每拍都能输出一个像素，无 FIFO、无帧缓存。
- **片上 ROM 代替帧缓存**：4 张图共 11 712 × 12 bit ≈ 137 Kbit，直接映射到 BSRAM；
  背景按 8×8 像素块放大（`x_in[11:3]`、`y_in[11:3]`）以节省存储。
- **管道滚动复用**：5 个管道寄存器组成移位链，每当最右侧管道越过 512 px 就从 640 px
  重新出场并刷新高度，只用 5 组寄存器就实现了持续滚动的管道流。
- **跨时钟域极简**：串口只有 9600 bps，用 `rgb_clk`（25 MHz）直接采样，
  `rx_d0/rx_d1` 两级同步后做下降沿检测；`rx_data_valid` 单拍脉冲送入游戏控制。

## 6. 已知问题

代码审查结论见 [`docs/CODE_REVIEW.md`](docs/CODE_REVIEW.md)，其中 **P0 级**两项
